# 2026-08-19

- Researched whether a persistent agentic OS can run inside Kiro. Answer: yes, but
  only on the primitives Web actually loads — steering, skills, specs, bash, git.
- Established the binding constraints. Hooks, custom agents, and repo `mcp.json`
  are unavailable on Kiro Web; the sandbox is torn down per task. Recorded in
  [[Kiro Web Capability Matrix]] and [[Git Is The Disk]].
- Chose `inclusion: always` steering as the boot loader instead of a
  `SessionStart` hook. Decision and tradeoff written up.
- Built the runtime: `bin/os` (boot/log/lesson/note/decide/recall/loop/dash/save/
  selftest), `bin/osutil.py` for parsing and the dashboard, seeded `brain/`.
- Adapted the Ralph loop to a surface where the agent can't re-invoke itself: the
  ledger is the loop counter, the session is the loop body. See [[Ralph Loop]].
- Skipped a vector store. Grep plus a hot `STATE.md` covers retrieval at this
  scale; reasoning in [[Grep Beats Embeddings Here]].
