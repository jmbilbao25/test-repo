=== the public path and the internal path are not the same ===
    /api/products/1002 at the gateway is /products/1002 at the service.
$ curl -s -o /dev/null -w 'gateway  %{http_code}  %{time_total}s\n' http://localhost:8091/api/products/1002
gateway  200  0.001988s

$ curl -s -o /dev/null -w 'direct   %{http_code}  %{time_total}s\n' http://127.0.0.1:8000/products/1002
direct   200  0.001733s
